# JobNavigator demo

A live, read-only demo of [JobNavigator](https://github.com/vesaias/JobNavigator): https://vesaias.github.io/JobNavigator-demo/ (sample data, no backend; job postings are snapshots, not affiliated with the companies).
`layer/` is the in-browser demo server, `data/` the sample data and page snapshots, and the Pages workflow builds the real dashboard from a JobNavigator ref with that layer added.
